This software helps you organize your daily work. It tracks your tasks and keeps your schedule in order. You gain control over your time by using this simple interface. * Date reminders for important events

## 💡 Using the application
Open the program by clicking the desktop icon. Create your first list by clicking the plus button at the top corner of the window. Type a name for your list and press enter. Add items to your list by typing in the box below the title. Mark any finished task by clicking the empty box next to the text. The software saves your work every time you change a setting or add an item. 

## 🛡️ Managing your data
The application maintains a local database file on your machine. You can find this file in the documents folder under the application name. Back up this file to an external drive or cloud service to prevent data loss. You can restore your data by placing the backup file back into the document folder. Use the settings menu to change the location of your backup folder if you prefer a different drive.

## ⚙️ Adjusting your preferences
